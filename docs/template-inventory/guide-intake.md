# Ingreso de guías para casos nuevos

Los casos únicos restantes no se clasifican por parecido de nombre.
El cliente debe ingresar una guía técnica antes de crear una familia o alias.

## Datos obligatorios
- nombre del equipo;
- función técnica;
- checklist o pauta;
- estructura relevante del informe;
- nombres alternativos conocidos;
- informe real usado como evidencia;
- responsable y fecha.

## Decisión permitida
- familia existente;
- familia nueva;
- REVIEW;
- UNMAPPED.

## Regla operacional
1. ingresar la guía;
2. validar que esté completa;
3. revisar evidencia;
4. registrar la decisión;
5. recién entonces modificar el catálogo;
6. agregar prueba y ejecutar inventario.

Toda modificación futura del catálogo debe indicar la guía que la respalda.
El formato base está en `tools/template_inventory/guide_submission.example.json`.
