# Stage 0 evidence index

This snapshot freezes the Stage 0 result and its explanatory evidence.

## Method

- Original technical reports were the evidence.
- Function, checklist and relevant report structure defined a family.
- Brand, model, capacity, part number and label did not define a family.
- Decisions were applied to aliases and the inventory was rerun after each group.

## Closed result

- 557 reports
- 544 CONFIRMED
- 13 UNMAPPED
- 0 REVIEW

The complete per-report result is in `../inventory.json`.
The complete material alias catalog is in `../aliases.json`.
The exact classifier source used by Stage 0 is in `../classifier.js`.
The original classifier inputs are preserved as
`../classifier_catalog_base.json` and `../families_stage0_final.json`.

The 13 UNMAPPED reports remain a passive historical backlog.
